# Provenance

SEQUENCE was created on 2026-07-20.

The images under `design-reference/` come from Ford's collection of UML 2.x
sequence-diagram reference material. They inform the project's visual
vocabulary.

The text-language grammar conventions are inherited from Codecaine Canvas's
layout-lab v3: JSON remains the source of truth, programs are disposable
whole-program projections, numbers are identity, and indentation expresses
nesting.

The layout implementation is clean-room work. D2's `d2sequence` and
js-sequence-diagrams were consulted as references only; no code was copied
from either project.
